## Contest Project 2 Comments

This is a continuation of my Contest Project 1 game: Catchess. The following are requirements for this project to be considered complete:
- Refactor all subroutines
- Address all logic bugs for piece movement and board changes
- Break down Move.asm into smaller files
- Implement stalemate
- Implement 50 move rule (50 moves without a pawn move is a draw)
- Implement draw by 3-fold repetition
- Add feature that shows legal moves when a piece is selected
- Add feature that flips board after each move
- Add start new game feature after a game is complete
